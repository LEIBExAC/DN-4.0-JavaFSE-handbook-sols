# Week 4 – Spring REST using Spring Boot 3

This folder contains the mandatory and additional important hands-on exercises for Week 4 of the DN Program, focused on building REST APIs using Spring Boot 3.

---

## Mandatory Hands-on

| #  | Skill                            | Filename                | Problem Statement                                         | Description                                                                 |
|----|----------------------------------|-------------------------|-----------------------------------------------------------|-----------------------------------------------------------------------------|
| 1  | Spring REST using Spring Boot 3  | 1. spring-rest-handson  | Create a Spring Web Project using Maven                   | Create a basic Spring Boot project using Maven and validate default setup.  |
| 2  | Spring REST using Spring Boot 3  | 1. spring-rest-handson  | Spring Core – Load Country from Spring Configuration XML  | Configure and load bean data (e.g., country) from XML file using Spring.    |
| 3  | Spring REST using Spring Boot 3  | 2. spring-rest-handson  | Hello World RESTful Web Service                           | Expose a basic GET REST endpoint returning a "Hello World" message.         |
| 4  | Spring REST using Spring Boot 3  | 2. spring-rest-handson  | REST - Country Web Service                                | Create a REST service that returns country data using a Java bean.          |
| 5  | Spring REST using Spring Boot 3  | 2. spring-rest-handson  | REST - Get country based on country code                  | Use path variables to fetch a country object based on a given code.         |
| 6  | Spring REST using Spring Boot 3  | 5. JWT-handson          | Create authentication service that returns JWT            | Implement JWT authentication using Spring Security and expose an endpoint.  |
